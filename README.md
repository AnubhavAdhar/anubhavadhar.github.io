# Anubhav Adhar — Professional Portfolio

A responsive, static portfolio website designed for GitHub Pages.

## Files
- `index.html` — website content
- `styles.css` — responsive dark navy / blue visual system
- `script.js` — mobile navigation and project filters
- `assets/Anubhav_Adhar_Resume.pdf` — downloadable resume
- `.nojekyll` — tells GitHub Pages to serve the static files as-is

## Publish free with GitHub Pages
1. Sign in at https://github.com/ (use the existing `AnubhavAdhar` account if it is yours).
2. Create a **public** repository named exactly `AnubhavAdhar.github.io` (GitHub usernames are case-insensitive in the URL; confirm your actual account username before creating it).
3. Upload the contents of this folder to the repository root. The `index.html` must be at the root, not inside another nested folder.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for the deployment to finish. Your site should be at `https://AnubhavAdhar.github.io/` (canonical URL will use lowercase username). GitHub says publishing can take several minutes.
8. In Settings → Pages, use **Visit site** to confirm the live URL.

Official guide: https://docs.github.com/en/pages/quickstart
